# Multi-Stage Trace Runs — S2 Retrofit (Halfpipe Round-Trip) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retrofit `s2_trace_recorder.lua` with an env-gated run mode: a stage-detour state machine, an embedded 48-column halfpipe row writer (minimal port — no RunObjects PC hooks), and run-manifest emission, so a level→halfpipe→level star-post round-trip records as a manifest-backed run; plus a synthetic S2 run fixture test and the recording procedure docs.

**Architecture:** The S2 engine/Java SS surface already shipped (`SpecialStageTraceData`, `S2SpecialStageReplayHarness`, `AbstractS2SpecialStageTraceReplayTest`, `Sonic2SpecialStageComparisonState`) and `TraceMetadata`/`TraceRunManifest`/`TraceCatalog`/the visual run branch already accept `game:"s2"` runs — **this plan is recorder + fixture + docs only; zero `src/main` changes.** The detour state machine mirrors the S1/S3K ports, with one structural difference: the S2 level recorder is a single-flat-output-dir recorder driven by an existing byte-stable workflow (`record_s2_level_select_traces.ps1`), so run mode (per-segment subdirectories + manifest) activates ONLY when `OGGF_TRACE_RUN_ID` is set; without it the recorder behaves exactly as today (a `$10` edge finalizes and stops).

**Tech Stack:** BizHawk Lua, JUnit 5/Jupiter, existing trace framework.

## Global Constraints

- **Comparison-only invariant** (trace-replay-bug-fixing skill); **no zone/route/frame carve-outs**; **ROM-only runtime assets**; JUnit 5/Jupiter only.
- **Byte-stability of the existing S2 workflow is a hard requirement:** with `OGGF_TRACE_RUN_ID` unset, `s2_trace_recorder.lua` must produce byte-identical artifacts to today for every existing invocation path (`record_s2_trace.bat`, `record_s2_level_select_traces.ps1`, all `TRACE_PROFILE`s incl. `level_gated_reset_aware` segment-skipping) — **with exactly ONE permitted delta: the `lua_script_version` metadata string changes `"9.11-s2"` -> `"9.12-s2"`** (the version bump is required and `write_metadata` emits it unconditionally; `TraceMetadata.nativePreludeMode()` parses major/minor and accepts `9.12-s2`, verified at `TraceMetadata.java:84-104`). Run mode is opt-in.
- **`s2_ss_trace_recorder.lua` stays untouched** (spec: it remains the interior-only capture tool; its hook-driven aux contract `Assert-SsAuxCoverage` keeps applying to `traces/s2/special_stage` only).
- **Lua budget & placement:** `s2_trace_recorder.lua` has ~151 top-level `local` statements (200-local main-chunk limit). ALL new state/constants/functions added by this plan are **globals**. Placement rule (S1-maze lesson): the state-globals block goes near the top constants; ALL new global FUNCTIONS are defined AFTER the file-scope locals they capture — the last relevant local block is the State block (~L259–290, `started`/`finished`/`trace_frame`/`bk2_frame_offset`/`physics_file`/`aux_file`/forward-declared `close_files`) and the existing helpers `bk2_input_mask` (~L321) / `reset_recording_state` (~L435) / `write_metadata` (~L482) / `close_files` assignment (~L603); define new functions after ALL of these (i.e., after ~L603). A global function defined above a referenced local binds a nil global; the parse gate still passes and it explodes at the first live detour.
- **NO `event.onmemoryexecute` hooks in this port** (BizHawk allows 2 total; the interior recorder uses both; the spec defers the hooks decision to the first round-trip capture). Consequence, stated for reviewers: the run's `ss/` segment carries a REDUCED aux surface (no `run_objects_end`/`stage_finished`/`results_started` events) and therefore must NEVER be copied over `src/test/resources/traces/s2/special_stage` (which the hook-based `Assert-SsAuxCoverage` contract governs). The Task 3 README procedure states this prohibition explicitly.
- **Commit policy:** 7-trailer block on every non-merge commit; the lua commit justifies `Changelog: n/a: recorder tooling only, no engine change`; test/docs commits `Changelog: n/a: test-only change` / `n/a: docs only`. Stage exact paths only; never `git add -A`; never `git stash`. End commits with the session's `Co-Authored-By` / `Claude-Session` lines.
- **VERIFY-ON-FIRST-CAPTURE:** the state-machine RAM reads below reuse addresses already proven by the shipped interior recorder; only the transition-record addresses (`Saved_x_pos` family, `f_bigring`) are new reads — the recorder prints them at detour boundaries so the first real capture validates them.

**Behavior contract:**
1. `run_id = os.getenv("OGGF_TRACE_RUN_ID") or nil` (global). **Run mode iff `run_id ~= nil`.** All new behavior — segment subdirs, the detour branch, transitions, manifest — is gated on it. Without it, the existing `$10`-edge path (finalize + `finished = true`) is untouched, and no new file I/O occurs.
2. In run mode, the existing arm path redirects output into a per-segment subdir: at arm time set `current_segment_dir_token = string.format("seg%d_%s%d", level_segment_count + 1, start_zone_name, apparent_act_for(...) + 1)` where `level_segment_count` is a NEW global counting LEVEL arms only (incremented at each level arm; the ss segment does not consume a number — `#segments_done` would, wrongly, yield `seg3_` for the return level because the ss entry sits between the two level entries). Point the per-segment file opens at `OUTPUT_DIR .. current_segment_dir_token .. "/"` (create via the recorder's existing mkdir mechanism, once per segment). The metadata writer keeps writing into the segment dir. Plain mode keeps writing flat into `OUTPUT_DIR` exactly as today — implement by making the "effective output dir" a variable that equals `OUTPUT_DIR` in plain mode.
3. Detour state machine (port the S1 shape, S2 constants). **Placement is load-bearing and differs from a naive read of the S2 loop:** the S2 `on_frame_end` is structurally INVERTED vs S1/S3K — its `if not started then ... return end` arm block comes FIRST (~L1013–1093, unconditional return at ~L1092) and the non-level stop branch after (~L1095). The detour machine must sit at the **TOP of `on_frame_end`, ABOVE the `if not started` block** (after the new top-of-function movie-done guard, item 4b) — NOT merely "before ~L1095" — so (a) continuation `$10` frames reach it while `started` is true, and (b) the exit fall-through lands in the `if not started` arm gate below, which safely re-arms the return level segment. **`started` lifecycle, stated explicitly (mirrors s1_complete_run_recorder.lua: `start_ss_segment` sets `started = true` at ~L613; `finalize_ss_segment` sets `started = false` at ~L727):** `start_ss_segment` sets `started = true`, re-bases `bk2_frame_offset = emu.framecount()`, resets `trace_frame = 0`; `finalize_ss_segment` sets `started = false`. The machine is TWO sibling blocks (the exit check cannot live inside the `$10` branch — its condition requires `game_mode == $10`; mirror `s1_complete_run_recorder.lua:1201-1244`): **Block 1** `if run_id ~= nil and started and game_mode == GAMEMODE_SPECIAL_STAGE then` — entry (gated `detour_active ~= "special_stage"`): finalize the armed level segment (flush + `write_metadata()` + `append_level_segment_done(trace_frame)` + `close_files()` + `started=false; trace_frame=0`), push the `starpost_special` transition (indices `from = #segments_done - 1`, `to = #segments_done`, computed AFTER the finalize), `start_ss_segment()`, `detour_active = "special_stage"`, print the boundary record, `return`; continuation: `write_ss_row(); return`. **Block 2** (immediately after): `if detour_active == "special_stage" then finalize_ss_segment(); detour_active = nil end` — first non-`$10` frame closes the ss segment (`finalize_ss_segment` sets `started = false` AND `trace_frame = 0`, mirroring s1:727-728) and falls through to the arm gate below. Plain-mode reachability unchanged (whole branch gated on `run_id`). **SS frame-0 alignment (run-port convention, NOT the interior recorder's):** the entry frame returns WITHOUT writing a row, so ss row 0 is recorded on the next `$10` frame with `bk2_frame_offset` sampled at entry — the same alignment as the shipped S1 and S3K run ports (their entry paths also `return` before any row). The interior `s2_ss_trace_recorder.lua` records frame 0 immediately in its arming invocation — a one-frame difference; document the run convention in a comment at `start_ss_segment` so the first-capture verification and any future comparator work know which alignment the run's ss segment carries. Entry transition fields (VERIFY-ON-FIRST-CAPTURE prints): `mode_change_bk2_frame = emu.framecount()`, `special_bonus_entry_flag = mainmemory.read_u8(0xF7CD)` (`f_bigring`), `saved_x_pos = read_u16_be(0xFE32)`, `saved_y_pos = read_u16_be(0xFE34)`, `last_star_post_hit = read_u8(0xFE30)`, `rings_before = read_u16_be(0xFE20)`, `emeralds_before = read_u8(0xFFB1)`.
4. Post-SS level re-arm (run mode only): today the recorder STOPS at any non-level mode; in run mode, after `finalize_ss_segment()` the arm gate must be allowed to fire again for the return level segment (reset the arm state the way `reset_recording_state()` does WITHOUT deleting prior segment output — S2's `reset_recording_state` (~L435–458) `os.remove`s the flat `OUTPUT_DIR` metadata/physics/aux files; split it so the run-mode re-arm resets state only, never removes files). At that re-arm, push the `stage_exit` transition (gated on last `segments_done` kind == `"special_stage"`), with indices stated at the emitter: `from_segment = #segments_done - 1`, `to_segment = #segments_done` (at the re-arm point `segments_done` = [level, ss], so this yields 1 -> 2, matching the Task 2 fixture): `mode_change_bk2_frame`, `rings_after = read_u16_be(0xFE20)` (will be 0 — ROM zeroes on reload, record the truth), `emeralds_after = read_u8(0xFFB1)`. 4b. **Top-of-function movie-done guard, RUN MODE ONLY (shape from `s1_complete_run_recorder.lua` ~L1163–1182):** the existing BK2-end/`FINISHED` checks (~L1112–1131) sit BELOW the detour branch's `return`s, so a movie ending mid-`$10` would keep writing ss rows until FRAME_CAP. Add a guard at the very top of `on_frame_end` gated `if run_id ~= nil and ...` — **plain mode must not reach ANY new code here** (today's plain-mode recorder has no unarmed movie-end stop outside `HEADLESS`, and even the HEADLESS armed check stops on a different frame formula; a plain-mode-reachable guard changes stop frames and breaks byte-stability). The movie-done condition must use the recorder's EFFECTIVE movie length, not raw `movie.length()`: reuse the same `BK2_FRAME_COUNT`-override logic as the existing armed check (~L1112–1116; `movie.length()` under-reports in chromeless runs — a raw-length guard would silently truncate the ss tail or seg2 while still writing a valid-looking manifest, invisible to Step 6's plain-mode inspection).
