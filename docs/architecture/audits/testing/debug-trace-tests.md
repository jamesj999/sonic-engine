## Maven selection rules

The normal `maven-surefire-plugin` configuration uses Surefire's default test-name
discovery and excludes all `**/tests/trace/**/*.java`, plus the listed GL/visual
diagnostics. Thus matching sources outside `tests/trace` run normally only when their
names match `Test*`, `*Test`, `*Tests`, or `*TestCase`.

The `trace-replay` profile replaces that configuration and includes
`**/tests/trace/**/*.java` (with redundant narrower replay/bootstrap/regression includes).
It excludes `Debug*`, every filename containing `Debug`, `*Probe*`, and the same listed
GL/visual diagnostics. A profile-selected helper or abstract class is still not a runnable
JUnit class.

## Classification definitions

- `UNIT`: automated focused contract test, including fixture/parser/guard tests under the
  trace source tree when they do not replay a ROM session.
- `TRACE_REPLAY`: automated ROM- and trace-backed parity, scenario, regression, or replay
  chain.
- `DIAGNOSTIC_PROBE`: opt-in diagnostic or benchmark JUnit source, commonly output-heavy
  and deliberately excluded by Maven's Debug/Probe filters.
- `VISUAL_MANUAL`: manual or display-dependent visual check without a reliable automated
  oracle.
- `HELPER_ABSTRACT`: abstract base, harness, formatter/comparison helper, or other support
  source with no standalone JUnit execution.
- `SUSPICIOUS`: executable source whose static evidence reveals no assertion,
  mock-verification, timeout, inherited comparator, or other defensible oracle.

`Normal suite` and `Trace profile` describe file-filter selection, not whether the class
contains runnable tests. `Outcome` is intentionally static in this draft. Commands use
placeholder paths for verified user-supplied ROMs and do not imply any ROM is committed.
